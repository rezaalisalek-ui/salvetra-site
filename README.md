# Salvetra Mobile Web App MVP

A simple mobile-first web app prototype for Salvetra.

## Files
- `index.html` — full mobile web app
- `manifest.json` — PWA manifest
- `sw.js` — basic offline service worker

## Deploy on Vercel / GitHub
Upload these files to your GitHub repository root and commit changes.
Vercel will deploy automatically.

If your current website already has an `index.html`, replace it with this one only if you want the app to become the homepage.
